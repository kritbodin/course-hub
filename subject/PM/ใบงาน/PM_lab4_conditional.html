ใบงานฝึกปฏิบัติ บทที่ 4 การเลือกทำตามเงื่อนไข

วิชา การเขียนโปรแกรมคอมพิวเตอร์

สาขาวิทยาการคอมพิวเตอร์

อาจารย์ผู้สอน ดร.กริชบดินทร์ ผิวหอม

วัตถุประสงค์ของใบงานฝึกปฏิบัติ:

  1. เพื่อฝึกการใช้คำสั่ง if-else ในการเลือกทำตามเงื่อนไข
  2. เพื่อให้สามารถเขียนโปรแกรมตรวจสอบเงื่อนไขได้
  3. เพื่อฝึกการสร้าง Flow Chart สำหรับการตัดสินใจ
  4. เพื่อให้เข้าใจการใช้ Modulo Operator (%) ในการตรวจสอบเลขคู่คี่

โครงสร้างคำสั่ง if-else ในภาษา C:

// รูปแบบ if-else พื้นฐาน if (เงื่อนไข) { // คำสั่งที่จะทำงานเมื่อเงื่อนไขเป็นจริง } else { // คำสั่งที่จะทำงานเมื่อเงื่อนไขเป็นเท็จ } // ตัวอย่างการใช้ Modulo Operator if (number % 2 == 0) { printf("เลขคู่"); } else { printf("เลขคี่"); }

Modulo Operator (%):

  • number % 2 = หาเศษจากการหาร number ด้วย 2
  • ถ้าเศษเป็น 0 แสดงว่าเป็นเลขคู่
  • ถ้าเศษเป็น 1 แสดงว่าเป็นเลขคี่

แบบฝึกปฏิบัติ: การตรวจสอบเลขคู่และเลขคี่

สิ่งที่ต้องทำ:

ให้เขียนผังโปรแกรม (Flow chart) และโปรแกรมภาษา C ตามลำดับต่อไปนี้

  1. รับค่าจำนวนเต็มใดๆ ระหว่าง 50-100 จากผู้ใช้
  2. ตรวจสอบว่าจำนวนนั้นเป็นเลขคู่หรือเลขคี่
  3. ถ้าเป็นเลขคู่ ให้แสดง "เลขคู่" ออกทางหน้าจอ
  4. ถ้าเป็นเลขคี่ ให้แสดง "เลขคี่" ออกทางหน้าจอ

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อตรวจสอบว่าจำนวนเต็มที่ป้อนเข้ามาเป็นเลขคู่หรือเลขคี่
  • เพื่อฝึกการใช้คำสั่ง if-else และ Modulo Operator

2) รูปแบบผลลัพธ์ที่ต้องการ

  • แสดงผลการตรวจสอบออกทางจอภาพ
โปรแกรมตรวจสอบเลขคู่และเลขคี่ กรุณาใส่จำนวนเต็มระหว่าง 50-100: 75 -- Input Data -- Number = 75 -- Output Data -- ผลลัพธ์: เลขคี่
โปรแกรมตรวจสอบเลขคู่และเลขคี่ กรุณาใส่จำนวนเต็มระหว่าง 50-100: 84 -- Input Data -- Number = 84 -- Output Data -- ผลลัพธ์: เลขคู่

3) ข้อมูลนำเข้า

  • รับค่าจำนวนเต็มระหว่าง 50-100 จากผู้ใช้
  • ใช้การหารด้วย 2 และตรวจสอบเศษที่เหลือ
  • ถ้าเศษเป็น 0 = เลขคู่, ถ้าเศษเป็น 1 = เลขคี่

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • number = ตัวแปรเก็บจำนวนเต็มที่รับจากผู้ใช้ (int)

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. แสดงข้อความแนะนำให้ผู้ใช้ป้อนจำนวนเต็มระหว่าง 50-100
  3. รับค่าจำนวนเต็มจากผู้ใช้
  4. ตรวจสอบเงื่อนไข: ถ้า number % 2 == 0
    • เป็นจริง: แสดง "เลขคู่"
    • เป็นเท็จ: แสดง "เลขคี่"
  5. แสดงข้อมูล Input และ Output
  6. จบการทำงาน

การทำงานของ Modulo Operator (%):

เลข 50 % 2 = 0 (เศษ 0) → เลขคู่ เลข 51 % 2 = 1 (เศษ 1) → เลขคี่ เลข 52 % 2 = 0 (เศษ 0) → เลขคู่ เลข 53 % 2 = 1 (เศษ 1) → เลขคี่ ... เลข 84 % 2 = 0 (เศษ 0) → เลขคู่ เลข 85 % 2 = 1 (เศษ 1) → เลขคี่

โปรแกรมตัวอย่าง:

#include <stdio.h> int main() { int number; printf("โปรแกรมตรวจสอบเลขคู่และเลขคี่\n"); printf("กรุณาใส่จำนวนเต็มระหว่าง 50-100: "); scanf("%d", &number); printf("\n-- Input Data --\n"); printf("Number = %d\n", number); printf("-- Output Data --\n"); if (number % 2 == 0) { printf("ผลลัพธ์: เลขคู่\n"); } else { printf("ผลลัพธ์: เลขคี่\n"); } return 0; }

สัญลักษณ์สำหรับการเขียน Flow Chart:

  • รูปรี (Oval): Start และ End
  • รูปสี่เหลี่ยมผืนผ้า (Rectangle): การประมวลผล/การคำนวณ
  • รูปสี่เหลี่ยมขนมเปียกปูน (Parallelogram): Input/Output
  • รูปเพชร (Diamond): การตัดสินใจ/เงื่อนไข (number % 2 == 0)
  • ลูกศร (Arrow): ทิศทางการไหลของโปรแกรม

ขั้นตอนการเขียน Flow Chart สำหรับโจทย์นี้:

  1. เริ่มต้นด้วย Start
  2. แสดงข้อความและรับ Input: "กรุณาใส่จำนวนเต็มระหว่าง 50-100"
  3. การตัดสินใจ: number % 2 == 0 ?
    • ทาง Yes (True): แสดง "เลขคู่"
    • ทาง No (False): แสดง "เลขคี่"
  4. แสดง Input Data และ Output Data
  5. จบด้วย End

คำแนะนำในการทำแบบฝึกหัด:

  1. วิเคราะห์ปัญหา: ทำความเข้าใจการทำงานของ Modulo Operator (%)
  2. เขียน Flow Chart: เริ่มจาก Start → Input → Decision → Output → End
  3. เขียนโปรแกรม: ใช้ int สำหรับจำนวนเต็ม และ %d สำหรับ printf/scanf
  4. ทดสอบโปรแกรม: ลองใส่ค่าต่างๆ เพื่อตรวจสอบความถูกต้อง
  5. ตรวจสอบขอบเขต: ให้แน่ใจว่าผู้ใช้ป้อนตัวเลขระหว่าง 50-100

หมายเหตุสำคัญ:

  • ใช้ %d สำหรับรับและแสดงจำนวนเต็ม (int)
  • ใช้ & หน้าตัวแปรใน scanf("%d", &number);
  • เงื่อนไข number % 2 == 0 ใช้เครื่องหมาย == (เปรียบเทียบ) ไม่ใช่ = (กำหนดค่า)
  • ใส่ \n เพื่อขึ้นบรรทัดใหม่
  • Decision Box ใน Flow Chart ต้องมีทางออก 2 ทาง (Yes/No หรือ True/False)
