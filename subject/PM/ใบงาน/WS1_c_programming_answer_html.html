เฉลยใบงานฝึกปฏิบัติ บทที่ 1 หลักการเขียนโปรแกรมคอมพิวเตอร์

วิชา การเขียนโปรแกรมคอมพิวเตอร์

สาขาวิทยาการคอมพิวเตอร์

อาจารย์ผู้สอน ดร.กริชบดินทร์ ผิวหอม

คำอธิบายส่วนสำคัญ:

การประกาศตัวแปร: float base, height, area;

  • float = ชนิดข้อมูลสำหรับเลขทศนิยม
  • ประกาศตัวแปร 3 ตัว คือ base, height, area

การรับข้อมูล: scanf("%f", &base);

  • scanf() = Scan Formatted คือคำสั่งรับข้อมูลจากแป้นพิมพ์
  • "%f" = รูปแบบข้อมูลประเภท float
  • &base = ตำแหน่งในหน่วยความจำของตัวแปร base

การคำนวณ: area = (base * height) / 2;

  • สูตรพื้นที่สามเหลี่ยม = (ฐาน × สูง) ÷ 2
  • ใส่วงเล็บเพื่อกำหนดลำดับการคำนวณ

การแสดงผล: printf("%.2f", area);

  • %.2f = แสดงทศนิยม 2 ตำแหน่ง

แบบฝึกปฏิบัติที่ 3: การคำนวณพื้นที่วงกลม

โปรแกรมที่ถูกต้อง:

#include <stdio.h> int main() { float radius, area; float pi = 3.14159; printf("โปรแกรมคำนวณพื้นที่วงกลม\n"); printf("กรุณาใส่รัศมีของวงกลม: "); scanf("%f", &radius); area = pi * radius * radius; printf("\n-- Input Data --\n"); printf("Radius = %.2f\n", radius); printf("-- Output Data --\n"); printf("Area = %.2f\n", area); return 0; }

ตัวอย่างการทำงาน:

โปรแกรมคำนวณพื้นที่วงกลม กรุณาใส่รัศมีของวงกลม: 7 -- Input Data -- Radius = 7.00 -- Output Data -- Area = 153.94

คำอธิบายส่วนสำคัญ:

การกำหนดค่าคงที่: float pi = 3.14159;

  • กำหนดค่า π (pi) = 3.14159
  • ใช้ชนิดข้อมูล float เพื่อเก็บเลขทศนิยม

การคำนวณ: area = pi * radius * radius;

  • สูตรพื้นที่วงกลม = π × r²
  • เขียน radius * radius แทน radius²

สรุปแนวคิดสำคัญจากทั้ง 3 แบบฝึกปฏิบัติ:

1. โครงสร้างโปรแกรม C:

#include <stdio.h> // เรียกใช้ไลบรารี่ int main() { // ฟังก์ชันหลัก // ประกาศตัวแปร // คำสั่งต่างๆ return 0; // คืนค่า }

2. การทำงานกับข้อมูล:

  • การประกาศตัวแปร: float ชื่อตัวแปร;
  • การรับข้อมูล: scanf("%f", &ตัวแปร);
  • การแสดงผล: printf("%.2f", ตัวแปร);
  • การคำนวณ: ใช้เครื่องหมาย +, -, *, /

3. จุดสำคัญที่ต้องจำ:

  • ใส่ & หน้าตัวแปรใน scanf()
  • ใช้ %.2f เพื่อแสดงทศนิยม 2 ตำแหน่ง
  • ใส่ \n เพื่อขึ้นบรรทัดใหม่
  • ใส่ ; ปิดท้ายคำสั่งทุกบรรทัด
  • ใส่วงเล็บ () ในการคำนวณเพื่อกำหนดลำดับ

4. การตรวจสอบโปรแกรม:

  • ตรวจสอบการใส่วรรคตอน ; {} ()
  • ตรวจสอบการเขียนชื่อฟังก์ชันให้ถูกต้อง
  • ทดสอบรันโปรแกรมและใส่ข้อมูลทดสอบ
  • ตรวจสอบผลลัพธ์ว่าถูกต้องตามคำนวณหรือไม่

แบบฝึกปฏิบัติที่ 1: Hello World Program

โปรแกรมที่ถูกต้อง:

#include <stdio.h> int main() { printf("Hello, World!\n"); printf("ยินดีต้อนรับสู่การเขียนโปรแกรม C\n"); return 0; }

ผลลัพธ์ที่ได้:

Hello, World! ยินดีต้อนรับสู่การเขียนโปรแกรม C

คำอธิบายการทำงานของโปรแกรม:

บรรทัดที่ 1: #include <stdio.h>

  • เป็นการเรียกใช้ไลบรารี่ Standard Input/Output
  • ทำให้สามารถใช้ฟังก์ชัน printf() และ scanf() ได้

บรรทัดที่ 3: int main() {

  • เป็นจุดเริ่มต้นของโปรแกรม (Main Function)
  • โปรแกรม C ทุกโปรแกรมต้องมีฟังก์ชัน main()

บรรทัดที่ 4-5: printf()

  • printf() = Print Formatted คือคำสั่งแสดงผลออกทางจอภาพ
  • \n = New Line คือการขึ้นบรรทัดใหม่

บรรทัดที่ 6: return 0;

  • คืนค่า 0 ให้กับระบบปฏิบัติการ แสดงว่าโปรแกรมทำงานสำเร็จ

แบบฝึกปฏิบัติที่ 2: การคำนวณพื้นที่สามเหลี่ยม

โปรแกรมที่ถูกต้อง:

#include <stdio.h> int main() { float base, height, area; printf("โปรแกรมคำนวณพื้นที่สามเหลี่ยม\n"); printf("กรุณาใส่ความยาวฐาน: "); scanf("%f", &base); printf("กรุณาใส่ความสูง: "); scanf("%f", &height); area = (base * height) / 2; printf("\n-- Input Data --\n"); printf("Base = %.2f\n", base); printf("Height = %.2f\n", height); printf("-- Output Data --\n"); printf("Area = %.2f\n", area); return 0; }

ตัวอย่างการทำงาน:

โปรแกรมคำนวณพื้นที่สามเหลี่ยม กรุณาใส่ความยาวฐาน: 10 กรุณาใส่ความสูง: 5 -- Input Data -- Base = 10.00 Height = 5.00 -- Output Data -- Area = 25.00
