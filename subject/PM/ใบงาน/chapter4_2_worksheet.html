ใบงานฝึกปฏิบัติ บทที่ 4-2 การเลือกทำตามเงื่อนไข (การคิดเกรด)

วิชา การเขียนโปรแกรมคอมพิวเตอร์

สาขาวิทยาการคอมพิวเตอร์

อาจารย์ผู้สอน ดร.กริชบดินทร์ ผิวหอม

วัตถุประสงค์ของใบงานฝึกปฏิบัติ:

  1. เพื่อฝึกการใช้คำสั่ง if-else แบบซ้อน (Nested if-else) ในการตรวจสอบหลายเงื่อนไข
  2. เพื่อให้สามารถเขียนโปรแกรมคิดเกรดจากคะแนนได้
  3. เพื่อฝึกการสร้าง Flow Chart สำหรับการตัดสินใจแบบหลายขั้นตอน
  4. เพื่อให้เข้าใจการใช้ Logical Operators (&& และ ||) ในการตรวจสอบช่วงข้อมูล

เกณฑ์การให้เกรด:

เกรด ช่วงคะแนน คำอธิบาย
A 80 - 100 ดีเยี่ยม (Excellent)
B 70 - 79 ดี (Good)
C 60 - 69 พอใช้ (Fair)
D 50 - 59 อ่อน (Poor)
E 0 - 49 ไม่ผ่าน (Fail)

โครงสร้างคำสั่ง if-else แบบซ้อน (Nested if-else):

// รูปแบบ if-else แบบซ้อนสำหรับหลายเงื่อนไข if (เงื่อนไขที่ 1) { // คำสั่งสำหรับเงื่อนไขที่ 1 } else if (เงื่อนไขที่ 2) { // คำสั่งสำหรับเงื่อนไขที่ 2 } else if (เงื่อนไขที่ 3) { // คำสั่งสำหรับเงื่อนไขที่ 3 } else { // คำสั่งสำหรับกรณีอื่นๆ } // ตัวอย่างการใช้สำหรับการคิดเกรด if (score >= 80 && score <= 100) { printf("เกรด A"); } else if (score >= 70 && score <= 79) { printf("เกรด B"); } else if (score >= 60 && score <= 69) { printf("เกรด C"); } else if (score >= 50 && score <= 59) { printf("เกรด D"); } else { printf("เกรด E"); }

Logical Operators:

  • && = AND (และ) - ทั้งสองเงื่อนไขต้องเป็นจริง
  • || = OR (หรือ) - เงื่อนไขอย่างน้อยหนึ่งข้อต้องเป็นจริง
  • ! = NOT (ไม่) - กลับค่าความจริง

แบบฝึกปฏิบัติ: โปรแกรมคิดเกรดจากคะแนน

สิ่งที่ต้องทำ:

ให้เขียนผังโปรแกรม (Flow chart) และโปรแกรมภาษา C ตามลำดับต่อไปนี้

  1. รับค่าคะแนนที่เป็นจำนวนเต็มไม่เกิน 100 จากผู้ใช้
  2. ตรวจสอบคะแนนและกำหนดเกรดตามเกณฑ์ที่กำหนด
  3. แสดงคะแนนและเกรดที่ได้ออกทางหน้าจอ
  4. แสดงคำอธิบายระดับผลการเรียน

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อคิดเกรดจากคะแนนตามเกณฑ์ที่กำหนด
  • เพื่อฝึกการใช้คำสั่ง if-else แบบซ้อนและ Logical Operators

2) รูปแบบผลลัพธ์ที่ต้องการ

  • แสดงคะแนน เกรด และคำอธิบายออกทางจอภาพ
โปรแกรมคิดเกรดจากคะแนน กรุณาใส่คะแนน (0-100): 85 -- Input Data -- Score = 85 -- Output Data -- Grade = A Description = ดีเยี่ยม (Excellent)
โปรแกรมคิดเกรดจากคะแนน กรุณาใส่คะแนน (0-100): 65 -- Input Data -- Score = 65 -- Output Data -- Grade = C Description = พอใช้ (Fair)
โปรแกรมคิดเกรดจากคะแนน กรุณาใส่คะแนน (0-100): 45 -- Input Data -- Score = 45 -- Output Data -- Grade = E Description = ไม่ผ่าน (Fail)

3) ข้อมูลนำเข้า

  • รับค่าคะแนนที่เป็นจำนวนเต็มระหว่าง 0-100 จากผู้ใช้
  • ใช้เงื่อนไขแบบซ้อนในการตรวจสอบช่วงคะแนน
  • กำหนดเกรดและคำอธิบายตามเกณฑ์ที่กำหนด

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • score = ตัวแปรเก็บคะแนนที่รับจากผู้ใช้ (int)
  • grade = ตัวแปรเก็บเกรดที่คำนวณได้ (char หรือ string)

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. แสดงข้อความแนะนำให้ผู้ใช้ป้อนคะแนนระหว่าง 0-100
  3. รับค่าคะแนนจากผู้ใช้
  4. ตรวจสอบเงื่อนไขแบบซ้อน:
    • ถ้า score >= 80 && score <= 100 → เกรด A (ดีเยี่ยม)
    • ถ้า score >= 70 && score <= 79 → เกรด B (ดี)
    • ถ้า score >= 60 && score <= 69 → เกรด C (พอใช้)
    • ถ้า score >= 50 && score <= 59 → เกรด D (อ่อน)
    • นอกนั้น → เกรด E (ไม่ผ่าน)
  5. แสดงข้อมูล Input, เกรด และคำอธิบาย
  6. จบการทำงาน

การทำงานของเงื่อนไขแบบซ้อน:

คะแนน 85: 85 >= 80 && 85 <= 100 → เป็นจริง → เกรด A คะแนน 75: 75 >= 70 && 75 <= 79 → เป็นจริง → เกรด B คะแนน 65: 65 >= 60 && 65 <= 69 → เป็นจริง → เกรด C คะแนน 55: 55 >= 50 && 55 <= 59 → เป็นจริง → เกรด D คะแนน 45: ไม่เข้าเงื่อนไขใด → เกรด E

ลำดับการตรวจสอบ:

โปรแกรมจะตรวจสอบเงื่อนไขจากบนลงล่าง หากพบเงื่อนไขที่เป็นจริงจะหยุดตรวจสอบและทำงานในส่วนนั้น

โปรแกรมตัวอย่าง:

#include <stdio.h> int main() { int score; char grade; printf("โปรแกรมคิดเกรดจากคะแนน\n"); printf("กรุณาใส่คะแนน (0-100): "); scanf("%d", &score); printf("\n-- Input Data --\n"); printf("Score = %d\n", score); printf("-- Output Data --\n"); if (score >= 80 && score <= 100) { grade = 'A'; printf("Grade = %c\n", grade); printf("Description = ดีเยี่ยม (Excellent)\n"); } else if (score >= 70 && score <= 79) { grade = 'B'; printf("Grade = %c\n", grade); printf("Description = ดี (Good)\n"); } else if (score >= 60 && score <= 69) { grade = 'C'; printf("Grade = %c\n", grade); printf("Description = พอใช้ (Fair)\n"); } else if (score >= 50 && score <= 59) { grade = 'D'; printf("Grade = %c\n", grade); printf("Description = อ่อน (Poor)\n"); } else { grade = 'E'; printf("Grade = %c\n", grade); printf("Description = ไม่ผ่าน (Fail)\n"); } return 0; }

สัญลักษณ์สำหรับการเขียน Flow Chart:

  • รูปรี (Oval): Start และ End
  • รูปสี่เหลี่ยมผืนผ้า (Rectangle): การประมวลผล/การกำหนดค่า
  • รูปสี่เหลี่ยมขนมเปียกปูน (Parallelogram): Input/Output
  • รูปเพชร (Diamond): การตัดสินใจ/เงื่อนไข
  • ลูกศร (Arrow): ทิศทางการไหลของโปรแกรม

ขั้นตอนการเขียน Flow Chart สำหรับโจทย์นี้:

  1. เริ่มต้นด้วย Start
  2. แสดงข้อความและรับ Input: "กรุณาใส่คะแนน (0-100)"
  3. การตัดสินใจครั้งที่ 1: score >= 80 && score <= 100 ?
    • Yes: แสดง "Grade = A, ดีเยี่ยม" → ไป End
    • No: ไปการตัดสินใจครั้งที่ 2
  4. การตัดสินใจครั้งที่ 2: score >= 70 && score <= 79 ?
    • Yes: แสดง "Grade = B, ดี" → ไป End
    • No: ไปการตัดสินใจครั้งที่ 3
  5. การตัดสินใจครั้งที่ 3: score >= 60 && score <= 69 ?
    • Yes: แสดง "Grade = C, พอใช้" → ไป End
    • No: ไปการตัดสินใจครั้งที่ 4
  6. การตัดสินใจครั้งที่ 4: score >= 50 && score <= 59 ?
    • Yes: แสดง "Grade = D, อ่อน" → ไป End
    • No: แสดง "Grade = E, ไม่ผ่าน" → ไป End
  7. จบด้วย End

คำแนะนำในการทำแบบฝึกหัด:

  1. วิเคราะห์ปัญหา: ทำความเข้าใจเกณฑ์การให้เกรดและช่วงคะแนน
  2. เขียน Flow Chart: ใช้ Decision Box หลายอันสำหรับแต่ละเงื่อนไข
  3. เขียนโปรแกรม: ใช้ if-else if-else แบบซ้อน และ && สำหรับตรวจสอบช่วง
  4. ทดสอบโปรแกรม: ลองใส่คะแนนในทุกช่วงเพื่อตรวจสอบความถูกต้อง
  5. ตรวจสอบขอบเขต: ทดสอบกับคะแนนขอบเขต (50, 59, 60, 69, 70, 79, 80, 100)

หมายเหตุสำคัญ:

  • ใช้ %d สำหรับรับและแสดงจำนวนเต็ม (int)
  • ใช้ %c สำหรับแสดงตัวอักษร (char)
  • ใช้ && (AND) สำหรับตรวจสอบช่วงคะแนน
  • เงื่อนไข score >= 80 && score <= 100 หมายถึงคะแนนต้องอยู่ระหว่าง 80-100
  • ลำดับการตรวจสอบเงื่อนไขสำคัญ - เริ่มจากเกรดสูงสุดลงมา
  • ใน Flow Chart แต่ละ Decision Box ต้องมีทางออก Yes/No
