วิชา การเขียนโปรแกรมคอมพิวเตอร์

สาขาวิทยาการคอมพิวเตอร์

อาจารย์ผู้สอน ดร.กริชบดินทร์ ผิวหอม

แบบฝึกปฏิบัติที่ 1: Hello World Program

คำแนะนำ:

ให้นักศึกษาพิมพ์โปรแกรมตัวอย่างด้านล่างตามตัวอักษร และทำความเข้าใจการทำงานของแต่ละส่วน

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อแสดงข้อความทักทาย Hello World ออกทางจอภาพ

2) รูปแบบผลลัพธ์ที่ต้องการ

  • พิมพ์ผลลัพธ์ออกทางจอภาพ ดังนี้
-- Output Data -- Hello, World! ยินดีต้อนรับสู่การเขียนโปรแกรม C

3) ข้อมูลนำเข้า

  • ไม่มีข้อมูลนำเข้าจากผู้ใช้
  • ใช้คำสั่ง printf() ในการแสดงข้อความ

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • ไม่มีตัวแปร (ใช้เฉพาะการแสดงข้อความ)

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. แสดงข้อความ "Hello, World!" ออกทางจอภาพ
  3. แสดงข้อความ "ยินดีต้อนรับสู่การเขียนโปรแกรม C" ออกทางจอภาพ
  4. จบการทำงาน

โปรแกรมที่ต้องพิมพ์:

#include <stdio.h> int main() { printf("Hello, World!\n"); printf("ยินดีต้อนรับสู่การเขียนโปรแกรม C\n"); return 0; }

แบบฝึกปฏิบัติที่ 2: การคำนวณพื้นที่สามเหลี่ยม

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อคำนวณพื้นที่สามเหลี่ยมจำนวน 1 รูป

2) รูปแบบผลลัพธ์ที่ต้องการ

  • พิมพ์ผลลัพธ์ออกทางจอภาพ ดังนี้
-- Input Data -- Base = 10.00 Height = 5.00 -- Output Data -- Area = 25.00

3) ข้อมูลนำเข้า

  • สูตรคำนวณพื้นที่สามเหลี่ยม Area = (Base × Height) ÷ 2
  • รับค่าความยาวฐานและความสูงของสามเหลี่ยมผ่านทางคีย์บอร์ด

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • Base = ตัวแปรที่ใช้เก็บความยาวฐานของสามเหลี่ยม
  • Height = ตัวแปรที่ใช้เก็บความสูงของสามเหลี่ยม
  • Area = ตัวแปรที่ใช้เก็บพื้นที่ของสามเหลี่ยม
  • โดยคำนวณได้จากสูตร Area = (Base × Height) ÷ 2

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. รับข้อมูลค่าความยาวฐานและความสูงของสามเหลี่ยมผ่านทางคีย์บอร์ด
  3. คำนวณพื้นที่สามเหลี่ยมตามสูตร Area = (Base × Height) ÷ 2
  4. พิมพ์ค่าความยาวฐาน ความสูง และพื้นที่สามเหลี่ยมออกทางจอภาพ
  5. จบการทำงาน

โปรแกรมที่ต้องพิมพ์:

#include <stdio.h> int main() { float base, height, area; printf("โปรแกรมคำนวณพื้นที่สามเหลี่ยม\n"); printf("กรุณาใส่ความยาวฐาน: "); scanf("%f", &base); printf("กรุณาใส่ความสูง: "); scanf("%f", &height); area = (base * height) / 2; printf("\n-- Input Data --\n"); printf("Base = %.2f\n", base); printf("Height = %.2f\n", height); printf("-- Output Data --\n"); printf("Area = %.2f\n", area); return 0; }

แบบฝึกปฏิบัติที่ 3: การคำนวณพื้นที่วงกลม

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อคำนวณพื้นที่วงกลมจำนวน 1 รูป

2) รูปแบบผลลัพธ์ที่ต้องการ

  • พิมพ์ผลลัพธ์ออกทางจอภาพ ดังนี้
-- Input Data -- Radius = 7.00 -- Output Data -- Area = 153.94

3) ข้อมูลนำเข้า

  • สูตรคำนวณพื้นที่วงกลม Area = π × Radius²
  • ค่า π (pi) = 3.14159
  • รับค่ารัศมีของวงกลมผ่านทางคีย์บอร์ด

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • Radius = ตัวแปรที่ใช้เก็บรัศมีของวงกลม
  • Area = ตัวแปรที่ใช้เก็บพื้นที่ของวงกลม
  • Pi = ตัวแปรที่ใช้เก็บค่า π (3.14159)
  • โดยคำนวณได้จากสูตร Area = Pi × Radius × Radius

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. กำหนดค่า π = 3.14159
  3. รับข้อมูลค่ารัศมีของวงกลมผ่านทางคีย์บอร์ด
  4. คำนวณพื้นที่วงกลมตามสูตร Area = π × Radius²
  5. พิมพ์ค่ารัศมีและพื้นที่วงกลมออกทางจอภาพ
  6. จบการทำงาน

โปรแกรมที่ต้องพิมพ์:

#include <stdio.h> int main() { float radius, area; float pi = 3.14159; printf("โปรแกรมคำนวณพื้นที่วงกลม\n"); printf("กรุณาใส่รัศมีของวงกลม: "); scanf("%f", &radius); area = pi * radius * radius; printf("\n-- Input Data --\n"); printf("Radius = %.2f\n", radius); printf("-- Output Data --\n"); printf("Area = %.2f\n", area); return 0; }

คำแนะนำในการทำแบบฝึกหัด:

  1. ให้พิมพ์โปรแกรมตามตัวอักษรทุกตัว อย่าข้ามหรือเปลี่ยนแปลงโค้ด
  2. ตรวจสอบการพิมพ์ ให้ครบถ้วนทุกบรรทัด รวมถึงเครื่องหมายวรรคตอนต่างๆ
  3. รันโปรแกรมทดสอบ หลังจากพิมพ์เสร็จแล้ว เพื่อดูผลลัพธ์
  4. ทดลองใส่ข้อมูลต่างๆ เพื่อดูการทำงานของโปรแกรม

หมายเหตุสำคัญ:

  • #include <stdio.h> = เรียกใช้ไลบรารี่สำหรับการรับและแสดงข้อมูล
  • scanf("%f", &ตัวแปร) = รับค่าทศนิยมจากแป้นพิมพ์
  • printf("%.2f", ตัวแปร) = แสดงทศนิยม 2 ตำแหน่ง
  • \n = ขึ้นบรรทัดใหม่
