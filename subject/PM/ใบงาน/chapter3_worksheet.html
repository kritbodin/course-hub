ใบงานฝึกปฏิบัติ บทที่ 3 โครงสร้างโปรแกรมภาษาซี

วิชา การเขียนโปรแกรมคอมพิวเตอร์

สาขาวิทยาการคอมพิวเตอร์

อาจารย์ผู้สอน ดร.กริชบดินทร์ ผิวหอม

วัตถุประสงค์ของใบงานฝึกปฏิบัติ:

  1. เพื่อฝึกกระบวนการคิดอย่างเป็นระบบ
  2. เพื่อให้สามารถเขียนโปรแกรมภาษาซีจาก Flow Chart ที่ออกแบบไว้ได้

แบบฝึกปฏิบัติที่ 1: การหาค่ามากที่สุด (Maximum)

สิ่งที่ต้องทำ:

ให้เขียนผังโปรแกรม (Flow chart) ตามลำดับต่อไปนี้

  1. กำหนดค่าให้ A, B, C เป็นจำนวนตัวเลข
  2. ตรวจสอบว่าค่าใดมากที่สุด (Maximum)
  3. ให้แสดงค่าที่มากที่สุดออกจากจอภาพ

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อหาค่าที่มากที่สุดจากตัวเลข 3 ตัว (A, B, C)

2) รูปแบบผลลัพธ์ที่ต้องการ

  • แสดงค่าที่มากที่สุดออกทางจอภาพ
-- Input Data -- A = 15.00 B = 8.00 C = 12.00 -- Output Data -- Maximum = 15.00

3) ข้อมูลนำเข้า

  • รับค่าตัวเลข A, B, C จากผู้ใช้
  • เปรียบเทียบค่าทั้ง 3 ตัวเพื่อหาค่าที่มากที่สุด

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • A = ตัวแปรเก็บตัวเลขที่ 1
  • B = ตัวแปรเก็บตัวเลขที่ 2
  • C = ตัวแปรเก็บตัวเลขที่ 3
  • max = ตัวแปรเก็บค่าที่มากที่สุด

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. รับค่า A, B, C จากผู้ใช้
  3. เปรียบเทียบ A กับ B หาค่าที่มากกว่า
  4. เปรียบเทียบผลลัพธ์จากข้อ 3 กับ C หาค่าที่มากที่สุด
  5. แสดงค่าที่มากที่สุดออกทางจอภาพ
  6. จบการทำงาน

สิ่งที่ต้องส่ง:

  1. สร้างไฟล์ผังโปรแกรม (Flow chart) ด้วยโปรแกรม diagrams.net บันทึกเป็น รหัส_ชื่อ.pdf (file/export as/.pdf)
  2. อัพโหลดไฟล์ผ่าน Google Classroom ในหัวข้อที่มอบหมายงาน

แบบฝึกปฏิบัติที่ 2: การหาค่าตรงกลาง (Middle Value)

สิ่งที่ต้องทำ:

ให้เขียนผังโปรแกรม (Flow chart) ตามลำดับต่อไปนี้

  1. กำหนดค่าให้ A, B, C เป็นจำนวนตัวเลข
  2. ตรวจสอบว่าค่าใดอยู่ตรงกลาง (Middle)
  3. ให้แสดงค่าจากข้อ 2 ออกจากจอภาพ

ตัวอย่าง:

A = 3; B = 5; C = 1; แสดงค่าที่อยู่ตรงกลาง คือ 3

การวิเคราะห์งาน:

1) วัตถุประสงค์ของการเขียนโปรแกรม

  • เพื่อหาค่าที่อยู่ตรงกลางจากตัวเลข 3 ตัว (A, B, C)
  • ค่าตรงกลาง คือ ค่าที่ไม่ใช่ค่าสูงสุดและไม่ใช่ค่าต่ำสุด

2) รูปแบบผลลัพธ์ที่ต้องการ

  • แสดงค่าที่อยู่ตรงกลางออกทางจอภาพ
-- Input Data -- A = 3.00 B = 5.00 C = 1.00 -- Output Data -- Middle Value = 3.00

3) ข้อมูลนำเข้า

  • รับค่าตัวเลข A, B, C จากผู้ใช้
  • เปรียบเทียบค่าทั้ง 3 ตัวเพื่อหาค่าที่อยู่ตรงกลาง

4) ตัวแปรที่ตั้งขึ้นเพื่อใช้ในโปรแกรม

  • A = ตัวแปรเก็บตัวเลขที่ 1
  • B = ตัวแปรเก็บตัวเลขที่ 2
  • C = ตัวแปรเก็บตัวเลขที่ 3
  • middle = ตัวแปรเก็บค่าที่อยู่ตรงกลาง

5) ขั้นตอนวิธีการทำงานของโปรแกรม

  1. เริ่มต้นทำงาน
  2. รับค่า A, B, C จากผู้ใช้
  3. ตรวจสอบเงื่อนไขต่างๆ เพื่อหาค่าตรงกลาง:
    • ถ้า A > B เป็นจริง
      • ถ้า A > C เป็นจริง แล้ว ถ้า B > C เป็นจริง แล้ว middle = B เท็จ middle = C
    • ถ้า A > B เป็นเท็จ
      • ถ้า A > C เป็นจริง แล้ว middle = A
      • ถ้า A > C เป็นเท็จ แล้ว ถ้า B > C เป็นจริง แล้ว middle = C เท็จ middle = B
  4. แสดงค่าที่อยู่ตรงกลางออกทางจอภาพ
  5. จบการทำงาน

สิ่งที่ต้องส่ง:

  1. สร้างไฟล์ผังโปรแกรม (Flow chart) ด้วยโปรแกรม diagrams.net บันทึกเป็น รหัส_ชื่อ.pdf (file/export as/.pdf)
  2. อัพโหลดไฟล์ผ่าน Google Classroom ในหัวข้อที่มอบหมายงาน

เคล็ดลับการเขียน Flow Chart:

  • รูปรี (Oval): ใช้สำหรับ Start และ End
  • รูปสี่เหลี่ยมผืนผ้า (Rectangle): ใช้สำหรับการประมวลผล/การคำนวณ
  • รูปสี่เหลี่ยมขนมเปียกปูน (Parallelogram): ใช้สำหรับ Input/Output
  • รูปเพชร (Diamond): ใช้สำหรับการตัดสินใจ (Decision)
  • ลูกศร (Arrow): ใช้แสดงทิศทางการไหลของโปรแกรม

คำแนะนำในการทำแบบฝึกหัด:

  1. วิเคราะห์ปัญหา: ทำความเข้าใจโจทย์ให้ชัดเจนก่อนเริ่มเขียน Flow Chart
  2. กำหนดตัวแปร: ระบุตัวแปรที่จำเป็นและประเภทข้อมูล
  3. เขียน Flow Chart: เริ่มจาก Start และจบด้วย End
  4. ตรวจสอบลำดับ: ให้แน่ใจว่าขั้นตอนเป็นไปตามลำดับที่ถูกต้อง
  5. ทดสอบด้วยตัวอย่าง: ลองใส่ค่าตัวอย่างเพื่อตรวจสอบความถูกต้อง

หมายเหตุสำคัญ:

  • Flow Chart ต้องมีจุดเริ่มต้น (Start) และจุดสิ้นสุด (End) เพียงจุดเดียว
  • ทุกขั้นตอนต้องเชื่อมต่อกันด้วยลูกศร
  • การตัดสินใจ (Decision) ต้องมีทางเลือก Yes/No หรือ True/False
  • ใช้ภาษาที่เข้าใจง่ายในการเขียนคำสั่ง
  • ตรวจสอบให้แน่ใจว่าไม่มี Dead Lock หรือ Infinite Loop
