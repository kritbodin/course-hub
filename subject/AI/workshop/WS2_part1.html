บทที่ 2 การแทนปัญหา - Block World Problem

วิชาปัญญาประดิษฐ์ สาขาวิทยาการคอมพิวเตอร์ มรภ.ศรีสะเกษ

🎯 วัตถุประสงค์ของคาบนี้

  1. เข้าใจหลักการการแทนปัญหาในรูปแบบ Well-Defined Problem
  2. สามารถกำหนด Initial State, Goal State, Actions และ Path Cost ได้
  3. ทำความเข้าใจปัญหา Block World Problem ที่เป็นปัญหาคลาสสิกใน AI
  4. ฝึกใช้อัลกอริทึม BFS ในการแก้ปัญหาเบื้องต้น
📚 ทฤษฎี: การแทนปัญหาแบบ Well-Defined Problem

องค์ประกอบของปัญหาที่ถูกต้อง

1. สถานะเริ่มต้น (Initial State)
สถานะของปัญหาในขณะเริ่มต้น เช่น ตำแหน่งของกล่องทั้งหมด
2. เซตของการกระทำ (Actions/Successor Function)
การกระทำที่สามารถทำได้ในแต่ละสถานะ เช่น หยิบกล่อง, วางกล่อง
3. สถานะเป้าหมาย (Goal State)
สถานะที่ต้องการให้เกิดขึ้น เช่น การเรียงกล่องตามต้องการ
4. ค่าใช้จ่าย (Path Cost)
จำนวนขั้นตอนหรือต้นทุนในการแก้ปัญหา เช่น จำนวนการเคลื่อนไหว
📝 ตัวอย่างในชีวิตจริง: การเดินทางจากบ้านไปมหาวิทยาลัย
  • Initial State: อยู่ที่บ้าน
  • Actions: เดิน, ขับรถ, นั่งรถเมล์
  • Goal State: อยู่ที่มหาวิทยาลัย
  • Path Cost: เวลาที่ใช้ หรือ ค่าใช้จ่าย
🧩 ปัญหา Block World Problem
📝 คำอธิบาย: ปัญหากล่องเป็นปัญหาคลาสสิกใน AI ที่ต้องเรียงกล่องจากสถานะเริ่มต้นไปยังสถานะเป้าหมาย
กฎสำคัญ:
  • หยิบได้ทีละกล่อง
  • หยิบได้เฉพาะกล่องที่อยู่บนสุด
  • ไม่สามารถหยิบกล่องที่ถูกซ้อนทับได้

ตัวอย่าง : ปัญหาง่าย - ย้าย A ไปวางบน B

# ===== Block World Problem - ตัวอย่างง่าย ===== # ตัวอย่างที่สามารถ run บน Google Colab ได้เลย import copy from collections import deque class BlockWorld: def __init__(self, initial_state, goal_state): self.initial_state = initial_state self.goal_state = goal_state def is_goal(self, state): """ตรวจสอบว่าถึงสถานะเป้าหมายแล้วหรือไม่""" # ลบ stack ว่างออกก่อนเปรียบเทียบ clean_state = [stack for stack in state if stack] clean_goal = [stack for stack in self.goal_state if stack] return clean_state == clean_goal def get_possible_moves(self, state): """หาการเคลื่อนไหวที่เป็นไปได้ทั้งหมด""" moves = [] # หากล่องบนสุดของแต่ละกอง (สามารถหยิบได้) for i, stack in enumerate(state): if stack: # ถ้ามีกล่องในกอง block = stack[-1] # กล่องบนสุด # ย้ายไปวางบนกองอื่น for j, target_stack in enumerate(state): if i != j: # ไม่ใช่กองเดิม new_state = copy.deepcopy(state) moved_block = new_state[i].pop() new_state[j].append(moved_block) moves.append((new_state, f"Move {block} from stack {i+1} to stack {j+1}")) # ย้ายไปวางเป็นกองใหม่ (บนโต๊ะ) new_state = copy.deepcopy(state) moved_block = new_state[i].pop() new_state.append([moved_block]) moves.append((new_state, f"Move {block} to table (new stack)")) return moves def bfs_solve(self): """แก้ปัญหาด้วย BFS""" queue = deque([(self.initial_state, [])]) visited = set() nodes_explored = 0 while queue: current_state, path = queue.popleft() nodes_explored += 1 # แปลงเป็น tuple เพื่อใช้เป็น key ใน set (ลบ stack ว่างก่อน) clean_state = [stack for stack in current_state if stack] state_key = tuple(tuple(stack) for stack in clean_state) if state_key in visited: continue visited.add(state_key) # แสดงสถานะที่กำลังตรวจสอบ print(f"ตรวจสอบสถานะ: {clean_state}") if self.is_goal(current_state): return path, nodes_explored for next_state, action in self.get_possible_moves(current_state): queue.append((next_state, path + [action])) return None, nodes_explored def print_state(self, state, title="State"): """แสดงสถานะของกล่อง""" print(f"\n{title}:") clean_state = [stack for stack in state if stack] for i, stack in enumerate(clean_state): print(f"Stack {i+1}: {stack}") if not clean_state: print("ไม่มีกล่อง") # ===== ตัวอย่างง่าย: ย้าย A ไปวางบน B ===== print("=== ตัวอย่างง่าย: ย้าย A ไปวางบน B ===") # สถานะเริ่มต้น: A และ B อยู่แยกกัน simple_initial = [['A'], ['B']] # สถานะเป้าหมาย: A อยู่บน B simple_goal = [['B', 'A']] simple_problem = BlockWorld(simple_initial, simple_goal) simple_problem.print_state(simple_initial, "สถานะเริ่มต้น") simple_problem.print_state(simple_goal, "สถานะเป้าหมาย") print("\n=== การแก้ปัญหาแบบง่าย ===") simple_solution, simple_nodes = simple_problem.bfs_solve() if simple_solution: print(f"\n✅ พบคำตอบใน {len(simple_solution)} ขั้นตอน:") for i, step in enumerate(simple_solution, 1): print(f"{i}. {step}") else: print("❌ ไม่พบคำตอบ")
ผลลัพธ์ที่คาดหวัง: === ตัวอย่างง่าย: ย้าย A ไปวางบน B === สถานะเริ่มต้น: Stack 1: ['A'] Stack 2: ['B'] สถานะเป้าหมาย: Stack 1: ['B', 'A'] === การแก้ปัญหาแบบง่าย === ตรวจสอบสถานะ: [['A'], ['B']] ตรวจสอบสถานะ: [['A', 'B']] ตรวจสอบสถานะ: [['B'], ['A']] ตรวจสอบสถานะ: [['B', 'A']] ✅ พบคำตอบใน 1 ขั้นตอน: 1. Move A from stack 1 to stack 2

💡 แบบฝึกหัด 1.1: ฝึกแก้ปัญหาด้วยตนเอง

ให้นักศึกษาแก้ไขโค้ดเพื่อแก้ปัญหาต่อไปนี้:

  • สถานะเริ่มต้น: [['A', 'B'], ['C']] (B อยู่บนสุด, A อยู่ล่างสุด, C อยู่แยกต่างหาก)
  • สถานะเป้าหมาย: [['B', 'C', 'A']] (B อยู่ล่างสุด, C อยู่กลาง, A อยู่บนสุด)
