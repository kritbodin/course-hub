เรื่อง: ความไม่แน่นอนและทฤษฎีของเบย์ (Uncertainty & Bayes' Theorem)

📖 ส่วนที่ 1: ทบทวนทฤษฎีของเบย์
📝 ความรู้พื้นฐาน: ทฤษฎีของเบย์เป็นเครื่องมือสำคัญในการคำนวณความน่าจะเป็นแบบมีเงื่อนไข โดยใช้ข้อมูลที่มีอยู่แล้วมาปรับปรุงการคาดการณ์

สูตรของเบย์

P(A|B) = [P(B|A) × P(A)] / P(B)

โดยที่:

  • P(A|B) = ความน่าจะเป็นของเหตุการณ์ A เมื่อเกิดเหตุการณ์ B แล้ว
  • P(B|A) = ความน่าจะเป็นของเหตุการณ์ B เมื่อเกิดเหตุการณ์ A แล้ว
  • P(A) = ความน่าจะเป็นของเหตุการณ์ A
  • P(B) = ความน่าจะเป็นของเหตุการณ์ B
🍪 ส่วนที่ 2: ปัญหาคุกกี้ - การใช้งาน Python
📝 โจทย์: วรรณเพ็ญหิวขนมกลางดึก มีชามคุกกี้ 2 ใบ แต่ละใบมี 40 ชิ้น
• ชามที่ 1: คุกกี้รสนม 30 ชิ้น, รสโกโก้ 10 ชิ้น
• ชามที่ 2: คุกกี้รสนม 20 ชิ้น, รสโกโก้ 20 ชิ้น
คำถาม: หาความน่าจะเป็นที่จะหยิบได้ชามใบที่ 2 และได้คุกกี้รสโกโก้

# ===== โจทย์คุกกี้: การใช้ทฤษฎีของเบย์ ===== import numpy as np import matplotlib.pyplot as plt # ข้อมูลปัญหา print("=== ปัญหาคุกกี้ของวรรณเพ็ญ ===") print("ชามที่ 1: รสนม 30 ชิ้น, รสโกโก้ 10 ชิ้น") print("ชามที่ 2: รสนม 20 ชิ้น, รสโกโก้ 20 ชิ้น") print() def solve_cookie_problem(): """ แก้ปัญหาคุกกี้โดยใช้ทฤษฎีของเบย์ หา P(ชามที่ 2 | คุกกี้รสโกโก้) """ # กำหนดตัวแปร # A = ชามที่ 2, B = คุกกี้รสโกโก้ # ความน่าจะเป็นเลือกชาม (เท่าๆ กัน) P_bowl1 = 0.5 # P(ชามที่ 1) P_bowl2 = 0.5 # P(ชามที่ 2) # ความน่าจะเป็นได้คุกกี้โกโก้จากแต่ละชาม P_cocoa_given_bowl1 = 10/40 # P(โกโก้|ชามที่ 1) = 10/40 P_cocoa_given_bowl2 = 20/40 # P(โกโก้|ชามที่ 2) = 20/40 print("=== ขั้นตอนการคำนวณ ===") print(f"P(ชามที่ 1) = {P_bowl1}") print(f"P(ชามที่ 2) = {P_bowl2}") print(f"P(โกโก้|ชามที่ 1) = {P_cocoa_given_bowl1}") print(f"P(โกโก้|ชามที่ 2) = {P_cocoa_given_bowl2}") print() # คำนวณ P(โกโก้) โดยใช้ Law of Total Probability P_cocoa = (P_cocoa_given_bowl1 * P_bowl1) + (P_cocoa_given_bowl2 * P_bowl2) print("=== คำนวณ P(โกโก้) ===") print(f"P(โกโก้) = P(โกโก้|ชามที่ 1) × P(ชามที่ 1) + P(โกโก้|ชามที่ 2) × P(ชามที่ 2)") print(f"P(โกโก้) = {P_cocoa_given_bowl1} × {P_bowl1} + {P_cocoa_given_bowl2} × {P_bowl2}") print(f"P(โกโก้) = {P_cocoa}") print() # คำนวณ P(ชามที่ 2|โกโก้) โดยใช้สูตรของเบย์ P_bowl2_given_cocoa = (P_cocoa_given_bowl2 * P_bowl2) / P_cocoa print("=== ใช้สูตรของเบย์ ===") print("P(ชามที่ 2|โกโก้) = [P(โกโก้|ชามที่ 2) × P(ชามที่ 2)] / P(โกโก้)") print(f"P(ชามที่ 2|โกโก้) = [{P_cocoa_given_bowl2} × {P_bowl2}] / {P_cocoa}") print(f"P(ชามที่ 2|โกโก้) = {P_bowl2_given_cocoa:.4f}") print(f"P(ชามที่ 2|โกโก้) = {P_bowl2_given_cocoa:.1%}") print() return { 'P_bowl1': P_bowl1, 'P_bowl2': P_bowl2, 'P_cocoa_given_bowl1': P_cocoa_given_bowl1, 'P_cocoa_given_bowl2': P_cocoa_given_bowl2, 'P_cocoa': P_cocoa, 'P_bowl2_given_cocoa': P_bowl2_given_cocoa } # แก้ปัญหา result = solve_cookie_problem() print("=== สรุปผลลัพธ์ ===") print(f"✅ ความน่าจะเป็นที่วรรณเพ็ญจะหยิบได้ชามที่ 2 และได้คุกกี้รสโกโก้") print(f"📊 คำตอบ: {result['P_bowl2_given_cocoa']:.4f} หรือ {result['P_bowl2_given_cocoa']:.1%}")
